# Magic LED — frontend

A Magic LED V3 é a vitrine Next.js do projeto acadêmico de Engenharia de Software II. O modo padrão usa o NestJS para catálogo, sessão, carrinho, endereços e pedidos. A área administrativa oferece leitura do catálogo. O checkout apresenta a revisão da seleção.

- [Executar a V3 e os testes](README-V3.md)
- [Contratos HTTP e limites da integração](../docs/FRONTEND_API_MAP.md)
- [Validação com NestJS, Prisma e PostgreSQL](../docs/FRONTEND_PROGRESS.md)
- [Relatório visual e referências da V3](../docs/MAGIC_LED_V3_RELATORIO.md)

A configuração local de exemplo do Next.js está em `.env.example`. Use um banco exclusivo para testes e siga o guia da V3 para iniciar o NestJS e a loja em processos separados.
